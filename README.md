# 🔄 Ultimate Text Reverser Suite

Welcome to the **Ultimate Text Reverser**, a comprehensive Python-powered web application for all your text reversal, transformation, and analysis needs.

Built with **Streamlit**, this app features a modern UI with neon accents (#7F00FF and #E100FF) and over 100+ combined features across 5 specialized pages.

## 🚀 Live Web App Pages

1.  **Standard Reverser**: Core reversal tools (Full text, Words, Sentences, Paragraphs).
2.  **Advanced & Smart Reverser**: Context-aware logic for Code (CamelCase, snake_case), URLs, HTML, and Brackets.
3.  **Creative & Fun Modes**: Visual effects including Zalgo/Glitch, Upside-down text, Matrix/Grid mode, and Diagonal reversal.
4.  **Analytics & Tools**: Palindrome checker, side-by-side diff comparison, and real-time processing stats (latency, memory).
5.  **SEO & Insights**: Deep dive into modern search optimization (GEO, AEO, AIO, SXO) and project disclaimers.

## 🛠️ Key Features

-   **Live Reverse Preview**: See your text transform instantly as you type.
-   **Contextual Safety**: Reverse text while keeping URLs, HTML tags, or code structure intact.
-   **Multiple Formats**: Export your results as TXT, JSON, or CSV.
-   **UI/UX**: Dark mode by default with a mobile-friendly responsive design.
-   **Performance**: Optimized local processing with simulated GPU/Web Worker scaling.
-   **Accessibility**: High-contrast themes and keyboard shortcut support.

## 📦 Installation & Setup

Ensure you have Python 3.8+ installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/mrshrivasta/text-reverser.git
    cd text-reverser
    ```

2.  **Install dependencies:**
    ```bash
    pip install streamlit pandas
    ```

3.  **Run the application:**
    ```bash
    streamlit run app.py
    ```
